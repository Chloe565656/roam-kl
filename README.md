# 同路 Roam · 吉隆坡

無建置步驟的多人旅程規劃工具。繁體中文、響應式排版，純 HTML / CSS / JavaScript。

## 開始使用

部署 `dist/` 到任何靜態主機（Cloudflare Pages、Netlify、GitHub Pages 等）。不需要環境變數或資料庫。

本機可在 dist 目錄啟動任一 HTTP server，例如 `python3 -m http.server 4173`，再開啟 http://localhost:4173 。請使用 localhost 或 HTTPS，才能使用 crypto.randomUUID 與剪貼簿功能。

## 流程

1. 修改自己的名字，完成 15 題偏好測驗。
2. 從 56 個地點中投票，支援關鍵字、分類與區域篩選。
3. 複製邀請連結，旅伴在自己的裝置加入，完成測驗及投票。
4. 旅伴複製「我的回覆」連結給召集人，召集人貼上並匯入。亦可交換 JSON 檔。
5. 行程頁設定天數、節奏、交通、預算、起訖時間，再產生路線與匯出文字行程。

多人協作透過快照合併，沒有即時同步。相同旅伴 ID 只採用時間戳較新的回覆，自己的資料不會被外部回覆覆寫。最多 30 位旅伴。連結內含名字、偏好與票選，僅分享給同行者；過長連結請改用 JSON。

資料在 localStorage `roam-kl-v1`。可匯出 JSON 備份，也能匯入另一旅程備份並確認切換。不同裝置並不自動同步。重新調整測驗會保留投票。

## 排程

每天以 KLCC 區域為出發參考點，從有票的地點中逐站選取：

`分數 = 票數 × 8 + 所有已完成測驗旅伴的類別偏好平均 × 3 − 直線公里 × 1.7 − 等待分鐘 / 12`

候選必須符合當日可用時段、地點規劃時段及每日預算。安排後不再重複。慢／中／快節奏分別最多 3／5／7 站，另留 40／25／10 分鐘緩衝。交通依直線距離與交通模式概估。這是可解釋的貪婪建議演算法，不保證全域最佳解。

## 資料限制

`dist/places.js` 為可直接編輯的 56 筆探索地點。名稱參考馬來西亞觀光局與吉隆坡旅遊指南：
- https://www.malaysia.travel/explore/top-places-to-visit-in-kuala-lumpur
- https://ebrochures.malaysia.travel/en/malaysia-travel-guide/kuala-lumpur/

座標、時段、停留時間、費用皆為排程估值，未逐筆核實最新營業狀態。現階段不處理每週休館日、日期、票券預約、午休或宗教場所分段開放。費用不含住宿、交通與購物。正式用於旅行前，請核實並更新資料；可擴充為每週分段時間表。

字型來自 Google Fonts，城市意象來自 Unsplash，未連線時使用系統字型與色塊背景。影像不是所有地點的實景。

## 檔案

- `dist/index.html`：頁面外殼
- `dist/style.css`：桌機與手機樣式
- `dist/places.js`：56 個地點資料
- `dist/app.js`：測驗、投票、協作、排程與匯出
- `.openai/hosting.json`：Sites 部署設定
